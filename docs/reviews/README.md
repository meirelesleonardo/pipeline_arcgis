# Histórico de code reviews (referência local)

Registros de revisões feitas no fluxo de estudo ([fluxo-fork-e-review.md](../fluxo-fork-e-review.md)). O comentário oficial continua na PR do GitHub da SMAS; aqui ficam contexto, decisões e pendências para consulta futura.

**Não** abrir PR desta pasta para o repositório oficial, salvo alinhamento do time.

## Como registrar uma nova revisão

1. Copie [\_template.md](_template.md) para `AAAA-MM-pr-NNN-<slug>.md`.
2. Preencha contexto, conclusão e findings que valem lembrar depois do merge.
3. Adicione uma linha na tabela abaixo.
4. Se o PR mudar contrato de produto (grão, Looker, planilha), linke o YAML/SQL do mart e atualize [estudo-e-code-review.md](../estudo-e-code-review.md) na tabela por domínio, se couber.
